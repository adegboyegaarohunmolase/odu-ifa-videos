# Odù Ifá Binary-Code Videos

Ten short videos on the Odù Ifá of migration, by Adegboyega Olukunle Arohunmolase. Each odù is shown as an 8-bit binary code — a single mark is 1, a double mark is 0 — rendered as falling binary rain, with an original synthesized talking-drum tune. 15 seconds each, vertical 720×1280, no narration.

| # | Odù | 8-bit signature | Theme |
|---|-----|----------------|-------|
| 01 | Ìrẹtẹ Méjì | 11011101 | Successful journey through sacrifice |
| 02 | Ògúndá Méjì | 11101110 | Bold migration & road clearing |
| 03 | Ọ̀sẹ́ Òtúrá | 10101011 | Overseas blessing |
| 04 | Òtúrá Méjì | 10111011 | Migration for knowledge |
| 05 | Ìrosùn Òsé | 11001010 | Trade and economic migration |
| 06 | Èjì Ògbè | 11111111 | Destiny guiding migration |
| 07 | Ìká Méjì | 01000100 | Peace in foreign land |
| 08 | Òyẹ̀kú Méjì | 00000000 | Protection during migration |
| 09 | Ọ̀wónrín Méjì | 00110011 | Leadership in new land |
| 10 | Ìrẹtẹ Òsé | 11011010 | Teaching / professional relocation |
